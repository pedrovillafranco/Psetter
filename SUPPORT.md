# Support

For usage questions and non-sensitive bug reports, open an issue in the
[Psetter GitHub repository](https://github.com/pedrovillafranco/psetter/issues).

For other support, email psetter@villafran.co.

Security and privacy vulnerabilities must be reported privately as described in
[`SECURITY.md`](SECURITY.md). Do not include real coursework answers,
credentials, or personal information in reports.
