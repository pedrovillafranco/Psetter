Psetter: Local Store Installation

1. Keep the private `psetter-infra` repository beside this repository.
2. From the repository root, run: pnpm extension:package
3. Open chrome://extensions in Chrome or another Chromium browser.
4. Enable Developer mode.
5. Choose Load unpacked.
6. Select dist/psetter-store.
7. Open an MITx PSET page. An ƒx button appears beside compatible answer fields.

This is the full Store build, including the private feedback and remote
configuration infrastructure. The public-safe build is available separately
with `pnpm extension:package:community` and intentionally omits that infrastructure.
