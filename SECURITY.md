# Security policy

Please report suspected security or privacy vulnerabilities privately to
psetter@villafran.co. Do not include real student answers, credentials, or other
sensitive information in a public issue.

Security reports are accepted for the current public release candidate and,
once published, the current Chrome Web Store release. Reports about
remote-code execution, origin/permission expansion, unintended answer-content
transmission, remote-config validation bypasses, or feedback-service abuse are
especially useful.

The project does not offer a bug bounty or guarantee a response time.
